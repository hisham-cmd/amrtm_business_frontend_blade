# سير عمل ملاحظات الإصدار (Release Note Workflow) - آمر تم

عند طلب المستخدم لإنشاء ملاحظات إصدار أو استخدام الأمر `/release-note` قم باتباع هذه القواعد الصارمة:

1. **جمع المعلومات**:
   - اسأل المستخدم عن نطاق التواريخ (من تاريخ X إلى تاريخ Y) أو رقم الإصدار
   - قم بالوصول إلى GitHub وتحليل commits للمستخدم `hisham-cmd` في المستودع: `amrtm_business`
   - ركز على الـ Commits في نطاق التواريخ المطلوب
   - صنف المهام إلى: ميزات جديدة (Features)، تحسينات (Enhancements)، إصلاح أخطاء (Bug Fixes)

2. **الأسلوب والكتابة**:
   - اكتب باللغة العربية الفصحى المبسطة
   - استخدم أسلوب مهني رسمي مناسب لوثيقة رسمية
   - المطور: **هشام الصغير**
   - مدير الفريق: **هشام قاسم الصغير**

3. **تصدير الوثيقة وتعبئة القالب**:
   - **الخيار الأول (موصى به - تلقائي بالكامل)**: استخدم أداة الأتمتة الذكية `auto_release_generator.py` لجمع الـ commits وتلخيصها عبر الذكاء الاصطناعي وتعبئة القالب تلقائياً بصيغ DOCX و PDF.
     - مسار السكريبت: `.agent/workflows/auto_release_generator.py`
     - مسار ملف التشغيل السريع: `.agent/workflows/run_release_workflow.bat` (فقط انقر عليه نقرة مزدوجة لبدء العمل!)
   - **الخيار الثاني (يدوي)**: استخدم سكريبت `generate_release.py` لإنشاء الملفات يدوياً بتمرير المعاملات.
     - مسار السكريبت: `.agent/scripts/generate_release.py`
   - مسار القالب المعتمد: `C:\react_projects\amrtm_business\إصدار رقم.docx`
   - مجلد التقارير والمستندات المولدة: `.agent/reports/`

4. **طريقة الاستخدام**:
   - **للتشغيل التلقائي بالكامل**:
     قم بتشغيل ملف الـ Batch المخصص من مجلد `workflows`:
     ```powershell
     cd .agent/workflows
     .\run_release_workflow.bat
     ```
     أو شغل الأمر مباشرة عبر الـ CLI مع تمرير المعاملات المطلوبة:
     ```powershell
     python .agent/workflows/auto_release_generator.py --version "1.0.0" --days 7 --pdf
     ```
   - **للتشغيل اليدوي (عبر السكربت القديم)**:
     ```powershell
     python .agent/scripts/generate_release.py ^
       --version "1.0.0" ^
       --date "2026-09-08" ^
       --time "10:00 م" ^
       --description "وصف مختصر للإصدار" ^
       --features "- الميزة الأولى\n- الميزة الثانية\n- إصلاح الأخطاء" ^
       --platform "تطبيق ويب (Laravel)" ^
       --testers "هشام قاسم الصغير" ^
       --developers "هشام الصغير" ^
       --team-manager "هشام قاسم الصغير" ^
       --upload-by "هشام الصغير" ^
       --signatory "هشام قاسم الصغير" ^
       --output ".agent/reports/إصدار رقم 1.0.0.docx" ^
       --pdf ".agent/reports/إصدار رقم 1.0.0.pdf"
     ```

5. **بنود الإصدار**:
   - تشمل جميع التغييرات منذ الإصدار السابق
   - تقسم إلى: ميزات جديدة، تحسينات، إصلاح أخطاء، تحديثات تقنية
   - تذكر أسماء المطورين والفريق

6. **تنسيق وثيقة الإصدار** (يتم تعبئته تلقائياً في القالب):
   ```
   إصدار رقم [X.X.X]
   تاريخ الإصدار: [التاريخ]
   
   المطور: هشام الصغير
   مدير الفريق: هشام قاسم الصغير
   
   الميزات الجديدة:
   * [وصف الميزة]
   
   التحسينات:
   * [وصف التحسين]
   
   إصلاح الأخطاء:
   * [وصف الإصلاح]
   
   تحديثات تقنية:
   * [وصف التحديث]
   ```
