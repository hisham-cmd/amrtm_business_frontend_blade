## الميزات الجديدة:
* إنشاء منصة آمر تم لإدارة الطلبات والخدمات الحكومية وقطاع الأعمال
* تصميم واجهة المستخدم الرئيسية مع نمط Corporate-UI المتكامل
* إنشاء نظام تسجيل المستخدمين (مقدم خدمة + عميل طالب خدمة)
* إنشاء دليل المستشارين مع فيزيتيات احترافية وبحث متقدم
* إنشاء واجهة تسجيل المنشآت مع دعم التخصصات والخدمات
* إضافة نظام تسجيل العقود المستقل

## التحسينات:
* توحيد النافبار الاحترافي Flowbite عبر جميع الصفحات
* تحسين تجربة المستخدم على الأجهزة المحمولة
* تحسين أداء تحميل صور الوزارات بأسماء UUID آمنة

## إصلاح الأخطاء:
* إصلاح صور الوزارات (404 على الإنتاج) بسبب أسماء عربية
* إصلاح مشكلة تسجيل الدخول (500 Internal Server Error)
* إصلاح مشكلة رفع المرفقات (415 Unsupported Media Type)

## التحديثات التقنية:
* بناء المشروع على Laravel 12 مع Tailwind CSS v4
* إضافة Flowbite 4.0.2 كمكتبة UI
* إنشاء هجرات قاعدة البيانات للتوسع المستقبلي
* إضافة اختبارات PHPUnit للميزات الجديدة
