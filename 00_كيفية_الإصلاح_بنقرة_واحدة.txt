          كيفية إصلاح OpenCode IDE بنقرة واحدة
══════════════════════════════════════════════════════════════

📌 ما هي هذه الملفات؟
──────────────────────

لديك 3 ملفات للإصلاح:

  1️⃣  إصلاح OpenCode - شغّل كمسؤول.bat
      ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
      • هذا الملف الرئيسي للإصلاح
      • انقر نقرة مزدوجة → سيطلب صلاحيات مسؤول → اضغط "نعم"
      • ستظهر نافذة زرقاء تعرض خطوات الإصلاح
      • في النهاية سيفتح تقرير يوضح ماذا تم
      
  2️⃣  إصلاح OpenCode - بدون نافذة.vbs
      ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
      • نفس الإصلاح لكن بدون نافذة CMD السوداء
      • مناسب إذا كنت تفضل إصلاح هادئ
      • الملف يعمل في الخلفية ولن ترى شيئاً
      • التقرير سيُحفظ في مجلد التقارير تلقائياً
      
  3️⃣  standalone_FIX_ALL.py
      ━━━━━━━━━━━━━━━━━━━━━
      • هذا هو المحرك الفعلي — لا تحتاج تشغيله مباشرة
      • الملفات أعلاه (BAT و VBS) تشغله تلقائياً
      • يمكنك تشغيله يدوياً من الطرفية إذا أردت:
        python standalone_FIX_ALL.py -y


📌 متى أستخدم الإصلاح؟
──────────────────────

  استخدم الإصلاح عندما ترى أي من هذه الأخطاء:
  
  ❌ "Free usage exceeded, subscribe to Go"
  ❌ "Rate limit exceeded: free-models-per-day"
  ❌ "Session too large to compact"
  ❌ "The model is blocked at the project level"
  ❌ OpenCode IDE لا يستجيب أو بطيء جداً


📌 كيف أعرف أن الإصلاح نجح؟
──────────────────────────

  ✅ النافذة تتحول إلى اللون الأخضر وتقول "تم الإصلاح بنجاح"
  ✅ يفتح تقرير نصي يوضح التفاصيل
  ✅ عند فتح OpenCode IDE يعمل بدون أخطاء
  ✅ مجلد التقارير على سطح المكتب يحتوي على تقرير جديد


📌 أين تُحفظ الملفات؟
──────────────────────

  📁 سطح المكتب / OpenCode_Fix_Reports /
     ├── fix_report_20260917_*.txt    ← تقارير الإصلاح
     └── backups/
         └── opencode_backup_*.zip    ← نسخ احتياطية


📌 ماذا أفعل إذا فشل الإصلاح؟
──────────────────────────────

  1. تأكد من إغلاق OpenCode IDE تماماً
  2. شغّل الإصلاح مرة أخرى
  3. إذا استمر الفشل، جرب مزود مختلف:
     
     افتح الطرفية (CMD) واكتب:
     python standalone_FIX_ALL.py --provider openrouter -y
     python standalone_FIX_ALL.py --provider groq -y
     python standalone_FIX_ALL.py --provider zen -y
     
  4. لتفعيل نماذج Groq المحظورة:
     افتح: https://console.groq.com/settings/project/limits
     وفعّل النماذج المطلوبة


📌 هل الإصلاح آمن؟
──────────────────

  ✅ نعم — يأخذ نسخة احتياطية قبل أي تعديل
  ✅ لا يرسل أي بيانات للإنترنت (إلا فحص بسيط للمزودين)
  ✅ لا يعدل ملفات النظام أو Registry
  ✅ يمكنك الرجوع للنسخة الاحتياطية في أي وقت
